# SBCI scripts

This directory contains the Python 3 SBCI scripts used by the ADNI workflow
wrappers in `ADNI_example/`.

The old `-py3` filename suffix has been removed because this repository is the
standalone Python 3 version of the pipeline. The wrapper scripts expect this
directory to be available through the `SBCI_SCRIPTS` environment variable.

For installation and workflow instructions, see the repository-level
`README.md` and `env_setup/README.md`.
